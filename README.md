# 마포자원순환네트워크 홈페이지

GitHub Pages(무료)에 올리는 정적 홈페이지입니다. 내용은 구글 시트에서, 연서명 신청은 Apps Script로 받습니다. 호스팅 비용은 들지 않습니다.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` 외 7개 | 홈, 소개, 활동, 목소리와 기록, 소식·일정, 소식 상세(`post.html#아이디`), 함께하는 사람들, 함께하기 |
| `assets/config.js` | **운영자가 고치는 유일한 설정 파일** — 구글 시트 ID, 신청서 웹앱 주소 |
| `assets/data.js` | 기본 내용. 시트를 연결하지 않았거나 시트를 못 읽을 때 이 내용을 보여 줍니다 |
| `assets/style.css`, `assets/site.js` | 디자인과 동작 |
| `apps-script/Code.gs` | 연서명 신청·현장 제안 → 시트 저장 + support@sslmo.at 알림 메일 |

## 1. GitHub Pages에 올리기

1. mapozerowaste@gmail.com 으로 GitHub 무료 계정을 만듭니다.
2. 새 저장소(public)를 만들고 이 폴더의 파일을 모두 올립니다. (웹에서 'Add file → Upload files'로 끌어다 놓으면 됩니다.)
3. 저장소 Settings → Pages → Branch를 `main` / `(root)`로 정하고 저장합니다.
4. 몇 분 뒤 `https://계정이름.github.io/저장소이름/` 에서 확인합니다.

## 2. 연서명 신청 연결

`apps-script/Code.gs` 맨 위 설명대로 설치하고, 받은 웹앱 주소를 `assets/config.js`의 `FORM_ENDPOINT`에 넣습니다.

## 3. 구글 시트로 내용 관리 (선택)

'홈페이지 콘텐츠' 스프레드시트를 만들고 아래 탭을 둡니다. 첫 줄은 열 이름입니다. `게시` 열에 `N`을 쓰면 그 줄은 숨겨집니다.

| 탭 | 열 이름 |
| --- | --- |
| 소식 | 아이디, 날짜, 분류, 제목, 요약, 본문, 안내, 예정(Y/N), 게시 |
| 활동 | 상태, 기간, 사업명, 설명, 함께한곳, 게시 |
| 논평 | 날짜, 종류, 제목, 링크, 게시 |
| 자료 | 날짜, 종류, 제목, 링크, 게시 |
| 언론 | 날짜, 매체, 제목, 링크, 게시 |
| 연혁 | 날짜, 내용, 게시 |
| 연서명명단 | 유형(단체/기업), 이름, 게시 |
| 협력 | 이름, 설명, 게시 |
| 설정 | 항목, 값 (개인 연서명 인원) |

시트 공유를 '링크가 있는 모든 사용자 — 뷰어'로 바꾸고, 주소의 `/d/`와 `/edit` 사이 ID를 `config.js`의 `SHEET_ID`에 넣습니다. 맨 위 줄이 가장 먼저 보이므로 최신 소식을 위에 씁니다. 시트는 공개되므로 개인 이름은 넣지 않고, 개인 연서명은 '설정' 탭에 인원수만 씁니다. 틀이 갖춰진 시트(홈페이지 콘텐츠)를 이미 만들어 두었습니다.

## 4. 도메인 연결

GitHub 저장소 Settings → Pages → Custom domain에 `mapozerowaste.org`를 넣고, 도메인 업체 DNS에서 GitHub Pages 안내에 나온 A 레코드(4개)와 `www` CNAME을 설정합니다. 새 사이트를 충분히 확인한 뒤에 바꾸고, 기존 구글 사이트는 한동안 지우지 않습니다.
